# PART 2 — 🔧 ENHANCEMENTS
## 20 Improvements to the Current Master Bible v5 Plan

---

### Agent System Enhancements

#### 🔧 1. Add "Emotional State Detection" to Princy
**Gap**: Princy responds warmly but doesn't detect *frustration*, *anxiety*, or *excitement* in user messages.

**Enhancement**: Before every response, Princy runs a 50-token emotion classifier:
- 😤 Frustrated → Extra empathy, skip upsells, escalate if needed
- 😰 Anxious → Reassuring tone, share success stats
- 🎉 Excited → Match energy, celebrate, soft upgrade nudge
- 😐 Neutral → Standard warm tone

**Cost**: ~₹0.005/message (Claude Haiku one-liner classification)

---

#### 🔧 2. Agent Memory System Upgrade
**Gap**: v5 mentions Redis for short-term memory (20 conversation turns). But there's no long-term memory architecture.

**Enhancement**: 3-tier memory system:
| Tier | Storage | Retention | Data |
|------|---------|-----------|------|
| Hot | Redis | 24 hours | Last 20 turns, active session |
| Warm | Supabase | Forever | User profile, resume history, preferences, career goals |
| Semantic | pgvector | Forever | Embedding of full career context — enables "remember when we discussed..." |

This lets Priya say: *"Last time you mentioned wanting to move into product management — I see a perfect role at Flipkart just posted!"*

---

#### 🔧 3. Add a 13th Agent: "Guru" — Learning & Upskilling
**Gap**: v5 has no agent for skill development. Users get told "you need React skills" but no path to learn.

**Enhancement**: **Guru** curates free/affordable courses from:
- YouTube (free)

Guru creates a personalized 4-week learning plan. Integrates with Priya's skill gap analysis.

### Key Technical Decisions Summary

| Decision | Recommendation | Reason |
|----------|---------------|--------|
| Frontend Framework | **Next.js 14 (App Router)** | SSR + SEO + Vercel native |
| Styling | **Tailwind CSS + shadcn/ui** | Fast, professional, accessible |
| Backend API | **Node.js + Express** | Auth, billing, webhooks |
| AI Microservice | **Python + FastAPI** | Best AI/ML ecosystem |
| Database | **Supabase PostgreSQL** | SQL + pgvector + auth + free tier |
| Cache | **Upstash Redis** | Serverless, pay-per-use |
| Compute | **Google Cloud Run** | Serverless, zero idle |
| AI Primary | **Claude Sonnet 4.6** | Best quality for career content |
| AI Volume | **Gemini 2.5 Flash** | Cheapest for high-volume tasks |
| AI Embeddings | **OpenAI text-embedding-3-small** | Best-in-class semantic search |
| Payments | **Razorpay** | India's best gateway |
| WhatsApp | **AiSensy** | Indian-first, Meta BSP |
| CDN | **Cloudflare Free** | DDoS protection + edge caching |
| CI/CD | **GitHub Actions** | Free tier + native integration |
| Monitoring | **Vikram + Cloud Run metrics** | Custom AI monitoring |
